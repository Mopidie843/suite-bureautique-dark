PUBLIER SUR GITHUB (installateur en ligne + mises à jour automatiques)
======================================================================
1. Sur github.com, créez un dépôt PUBLIC vide nommé : suite-bureautique-dark   (compte Mopidie843)
2. Envoyez-y le contenu de ce dossier (git init, git add ., git commit, git remote add origin ..., git push -u origin main)
   ou glissez-déposez les fichiers sur la page du dépôt.
3. Créez une version : git tag v3.3.0 && git push --tags
   -> GitHub Actions (onglet « Actions ») construit sur un vrai Windows et publie la « Release » avec :
      * SuiteBureautiqueDark-Setup-3.3.0.exe  = installateur COMPLET
      * l'installateur EN LIGNE (« Web Setup », petit : il télécharge l'application depuis GitHub pendant l'installation)
      * la version portable, latest.yml et les paquets de mise à jour
4. Les PC où l'application est INSTALLÉE vérifient GitHub au lancement : quand vous publiez la version suivante
   (changez "version" dans package.json, puis nouveau tag v3.4.0), elle se télécharge seule et propose de redémarrer.
   La version portable ne se met pas à jour automatiquement.
Note : sans certificat de signature, Windows SmartScreen affiche un avertissement au premier lancement.
